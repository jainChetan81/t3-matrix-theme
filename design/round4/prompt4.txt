2. The Watcher (board A: "Watcher — concepts and states")
Not a cute mascot. Think of the small animated brand glyphs that Codex, ChatGPT and Claude show while they think: a living icon, 20–32 px, drawn in the Possessed palette (#0affa0 accent, #010803 canvas, near-white heads, red #ff2d6f only for error). It sits on the top edge of the composer card, left side, half overlapping the border like a seal on the edge, and it watches. It reacts to app state, deterministically:
- idle: dormant. Still, or one very slow breath.
- composer focused: wakes and looks at you.
- typing (composer has text): follows or flickers with the input.
- agent working / streaming: decoding. Glyphs cycle, it scans; a small "bullet time" ripple is welcome.
- done: settles back.
- error: glitches red briefly, once, then recovers.
- reduced motion: a static pose per state, no animation.
Explore four concepts, each as one SVG plus a CSS state sheet, and show every state of every concept side by side in a grid (rows = concepts, columns = the seven states), at 1× and at 4× so I can judge the drawing:
  a. Glyph core: a tiny column or 3×3 cell of falling katakana with a white head.
  b. Sentinel eye: the machine eye, a lens with an iris that opens, tracks and scans.
  c. Lens: one sunglass lens with a green code reflection sliding across it.
  d. White rabbit, or a ringing phone-booth glyph: your choice of whichever draws better at 24 px.
Then pick one, say why, and show it larger in place on a real Possessed composer in each state (board B: "Watcher — in place").
How it must be built, because this is what the theme can do:
- It is a pseudo-element (::before or ::after) of the composer card or its wrapper, with the SVG as a data: URI background. The composer card's ::before is already the ❯ prompt and the input's block caret is taken, so use the card's ::after or a wrapper pseudo and tell me which.
- A pseudo has no children, so states are made by swapping the background image (one small SVG per state, or one sprite strip moved with background-position in steps()), plus transform/opacity animation on the pseudo itself. SVG-internal SMIL/CSS animation inside the data: SVG is fine at this size (the 14 px spinner already does it) and is the easy way to get the cycling glyphs and the iris.
- State selectors available in the real app (use placeholders @{…} like the Possessed kit; I'll map them):
  @{composer-input}:focus — focused
  @{composer-card}:has(@{composer-input} p:not(:has(> br:only-child))) or similar "editor has text" — typing. The editor is a contenteditable (ProseMirror) whose empty state is <p><br></p>. CSS can't see keystrokes, so "follows the input" has to be a loop or a state pose, not per-key.
  :root:has([data-streaming="true"]) — the agent's reply is streaming
  :root:has([data-thread-now-line]) — the thread is working (tool calls, thinking)
  :root:has(@{error-alert}) — an error alert is on screen
  "done" has no hook of its own: it is whatever plays when the streaming/working selector stops matching, so make it a one-shot settle on the idle/focused state.
- Deterministic: same state, same picture. No randomness, nothing that depends on timing luck.
- Calm enough to sit in the corner of my eye all day. Working is the only state that may loop; idle may have one very slow loop at most or none; everything else is one-shot.

4. Limits
- Budget: the whole theme is ≤ 20,000 characters of CSS including the inlined SVGs. Possessed already uses 14,735. Everything new in this round (Watcher SVGs + state CSS + the Matrix touches) must fit in about 4,500 characters. Give me the measured count per piece and the total.
- Performance: animate transform and opacity only; steps() where it suits; no filter, blur or backdrop-filter; no animated box-shadow or text-shadow; no text-shadow on body or code text; no new always-on loops except the Watcher's working state (and at most one very slow idle loop). One-shot effects must end. Bullet time should change the existing two rain layers (slow them or pause them with animation-play-state, or swap duration), not add layers. Ripple rings: one or two pseudo-elements scaling with opacity, only while streaming.
- prefers-reduced-motion: everything still; the Watcher shows a static pose per state.
- Readability first: nothing may sit over prose, code or the text I'm typing.
